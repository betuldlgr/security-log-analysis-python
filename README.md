# Security Log Analysis Project

This project analyzes network traffic data to detect malicious activity using the UNSW-NB15 dataset.

## Tools
- Python (pandas, seaborn, matplotlib)
- Scikit-learn (RandomForest)

## Key Features
- Log and network traffic analysis
- Data preprocessing and feature engineering
- Machine learning classification (attack vs normal)

## Results
The model successfully identifies patterns of malicious activity in network traffic data.
